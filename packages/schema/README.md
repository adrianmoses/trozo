# @trozo/schema

Single source of truth for the chunk service API contract.

The Pydantic v2 models in `services/chunker/app/models.py` define the HTTP request and response shapes (and, via `LLMDraft`, the LLM's structured output). This package holds the JSON Schema exported from those models and the TypeScript types generated from it, consumed by `apps/web` as `@trozo/schema`.

| File                | What it is                                                                        |
| ------------------- | --------------------------------------------------------------------------------- |
| `chunk.schema.json` | JSON Schema exported from Pydantic. Generated, do not edit.                       |
| `src/index.ts`      | TS types generated by `json-schema-to-typescript`. Generated, do not edit.        |
| `test/fixture.ts`   | A realistic `ChunkResponse` that must satisfy the types (also used by web tests). |

After changing the Pydantic models, regenerate both files and update the fixture:

```bash
cd services/chunker && uv run scripts/export_schema.py   # → chunk.schema.json
pnpm --filter @trozo/schema generate                     # → src/index.ts
pnpm --filter @trozo/schema test                         # tsc --noEmit against the fixture
```

Fields added to the contract should be optional with a default: cached responses are served as stored, and older entries will not have the new field.
